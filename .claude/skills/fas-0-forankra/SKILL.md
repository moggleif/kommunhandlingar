# Fas 0 – Förankra uppdraget

Bara analys: inga filändringar, ingen gren, inga commits.

1. Förstå uppdraget. Läs berört issue, `docs/02-KRAV.md`, `docs/03-ARKITEKTUR.md`
   och de beslut i `docs/decisions/` som rör området.
2. Hitta oklarheter, risker och dolda antaganden. Ifrågasätt dåliga idéer och
   föreslå bättre när det finns.
3. Är arbetet för stort för en sammanhängande pull request: dela upp det i
   mindre paket och föreslå ordningen.
4. Presentera din tolkning – omfattning, vad som inte ingår, öppna frågor och
   ditt förslag på hur de ska besvaras – och **vänta på bekräftelse**.

Frågor ställs så att de kan besvaras med ett ord, med en rekommendation
markerad.
